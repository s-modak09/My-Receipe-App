## About

Recipe App is an Android application that allows users to explore recipes through different food categories.

The application retrieves recipe data from the [TheMealDB API](https://www.themealdb.com/) and presents it through a clean and modern Jetpack Compose interface.

Users can browse available food categories, select a category, and explore recipes associated with it.

The project demonstrates practical experience with modern Android development, REST API integration, asynchronous network requests, JSON parsing, and declarative UI development.

---

## Features

- Browse recipes by food category
- Display food categories with images
- Explore recipes within a selected category
- Retrieve recipe data from TheMealDB API
- REST API integration using Retrofit
- JSON response parsing using Gson
- ViewModel-based application logic
- Kotlin Coroutines for asynchronous operations
- Modern Jetpack Compose UI
- Material 3 components
- Dynamic content loaded from an external API
